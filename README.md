# HugType

Site construit avec Next.js 16, React 19, Tailwind v4 et shadcn/ui (preset Nova). Voir `CLAUDE.md` pour le détail de la stack.

## Lancer le site

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000. La touche `d` bascule le dark mode.

## Ajouter des composants

```bash
npx shadcn@latest add card dialog input
```

Ils arrivent dans `components/ui/`.
